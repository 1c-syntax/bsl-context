Виджет (Widget)

По значениям

Синтаксис:

Новый Виджет(<Ключи>, <Значения>)

Параметры:

<Ключи> (необязательный)

Тип: Строка.
Список свойств, указанных через запятую.

<Значения> (необязательный)

Тип: Произвольный.
Значения элементов.

Описание:

Описание для теста.

Использование в версии:

Доступен, начиная с версии 8.0.
