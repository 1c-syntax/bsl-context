Виджет (Widget)

По диапазону

Синтаксис:

Новый Виджет(<Шаблон>, <Значение1-Значение10>)

Параметры:

<Шаблон> (обязательный)

Тип: Строка.
Строка шаблона.

<Значение1-Значение10> (необязательный)

Тип: Число.
Значения подстановки. Указываются через запятую.

Описание:

Описание для теста.

Использование в версии:

Доступен, начиная с версии 8.0.
